# 👗 GenAI Fashion Recommendator

An **AI-powered fashion recommendation chatbot** built using **LangFlow** and **Groq’s LLaMA-3** model.  
This project demonstrates how low-code AI workflows can analyze uploaded documents (like resumes or product data), perform data extraction using DataFrames, and generate intelligent, context-aware responses — including personalized fashion suggestions using **text and image similarity**.

---

## 🚀 Features

- 🧠 **AI Chatbot with Context Awareness** — Built with LangFlow and Groq LLaMA-3  
- 📄 **Document Upload & Analysis** — Upload `.docx` files and query content  
- 🧩 **DataFrame Operations** — Convert documents into structured tabular format  
- 💬 **Conversational Querying** — Ask natural-language questions about your file  
- 👗 **Fashion Recommendation System** — Uses text and image similarity for smart suggestions  
- ⚡ **Groq Inference Engine** — Ultra-fast LLaMA-3 performance  

---

## 🧰 Tools & Technologies

| Tool | Purpose |
|------|----------|
| **LangFlow** | Visual low-code framework for LLM workflows |
| **Groq Cloud** | High-speed inference engine for LLaMA-3 models |
| **LLaMA-3-70B** | Large Language Model for Q&A and reasoning |
| **Sentence Transformers** | Text embedding and similarity scoring |
| **Python / scikit-learn / NLTK** | Data analysis and text processing |

---

## ⚙️ Workflow Overview

1. **File Upload** → Upload a `.docx` (e.g., resume or fashion catalog).  
2. **DataFrame Conversion** → Convert content to a structured format.  
3. **LLM Agent (Groq)** → Process queries using contextual grounding (RAG).  
4. **Text/Image Similarity** → Generate intelligent apparel recommendations.  
5. **Response Generation** → View AI-powered results in the chat window.
